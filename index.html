Gear Ledger

● poll-synced LIVE

The server-authoritative task/event ledger for the CWI agent company. This repo is the server: versioned JSON, SHA-based atomic compare-and-swap writes, Ed25519 seals. No simulations — sample:false is mandatory on every live record.

Sync semantics (for clients)

  • Poll state.json with If-None-Match every ~10s.
  • Presence older than 30 min is stale — render honestly, never as live.
  • Reject any record with sample:true.
  • Two independent fetches see byte-identical state — compare content SHA-256.
